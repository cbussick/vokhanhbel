# Defer Card Collections

Cards may eventually span multiple language pairs, but V1 has no demonstrated need for decks, sets, or language-based grouping. We keep the `cards` model, review queues, and Card list flat; if mixed-language use proves to need grouping, a future ADR can introduce a collection relationship through a migration.

Superseded by [ADR-0012](0012-group-cards-into-collections.md).
